AutFin v7.0 — how it actually runs

Pydantic AI multi-agent system for NSE/BSE. Read from the live import graph, not the README.

live — imported and reachable legacy — present on disk, imported by nothing

1 · Runtime flow (one morning run)

01Daemon wakes up run.py

Starts Obscura MCP (headless browser) if the port is closed, then runs immediately on startup. After a run it sleeps until the next 09:15 IST, skips Sat/Sun, and fires the quarterly review every 90 days.

--mode paper | live | backtest --oncemarket hours 09:15–15:30 IST log → autfin.log
02Deps object is built types.py → AgentDeps

One Pydantic model carries everything the agents need: user_id, mode, capital (₹10L default), max_position_pct 0.30, sector_limit_pct 0.30, max_drawdown_pct 0.15, and the optional kite_client / vector_store handles. Every agent, tool and capability receives this same object as ctx.deps.

balance-is-budget: capital = deployable pool paper mode = no order ever leaves the box
03Supervisor plans and delegates agents/supervisor.py

A deep-tier LLM with 6 tools of its own (run_morning_routine, run_quarterly_review, handle_price_alert, analyze_symbol, execute_trade) plus 7 capabilities: SubAgents (the team), DynamicWorkflow (model writes its own orchestration script), Planning, Memory, SystemReminders, Thinking(high), WebSearch.

instructions from ManagedPrompt (Logfire, falls back to inline default)
045-phase routine supervisor.run_morning_routine()

The tool runs the sequence in Python, not in the prompt: market snapshot → analysis of up to 10 holdings in parallel via asyncio.gather → screening/research → risk assessment → conference for capital allocation. Each sub-agent is a full agent with its own model, tools, token budget and timeout.

sub-agent errors are contained (contain_errors=True) usage forwarded up to the supervisor
05Order decision supervisor.execute_trade()

TradeOrder in → if deps.mode == "paper" it only logs a simulated fill; in live it calls kite.place_order(...) on NSE and returns the order id. Missing Kite client returns an action="error" output instead of raising.

live orders are real money — mode comes from the CLI flag
06What is written down capability Memory(FileStore("./data/memory"))

Markdown memory files namespaced per user_id, injected back into the next run's context (max_tokens=5000, max_lines=500). Path is CWD-relative — run from the repo root. The SQLite/ChromaDB layer in src/autfin/memory/ is legacy and unused by this graph.

tests mutate the tracked data/memory/.memory-store.sqlite3

Port mismatch: the browser toolset dials OBSCURA_MCP_URL (default localhost:9222), while .env.example and mcp/browser_client.py document BROWSER_MCP_PORT 9333 / 8080. Nothing reconciles them — set the URL explicitly. The sentiment-scraping path additionally hardcodes openai:gpt-4.1-mini, which needs an OPENAI_API_KEY that .env.example does not mention.

Transport is not a native pydantic-ai provider: create_nvidia_model() wraps OpenAIChatModel with OpenAIProvider(base_url="https://integrate.api.nvidia.com/v1") and NVIDIA_NIM_API_KEY. Model ids change often because NIM rejects names and JSON-schema patterns it cannot compile (this is why prices are float, not Decimal). config/settings.py still names a third, older model — it is read only by legacy modules.
